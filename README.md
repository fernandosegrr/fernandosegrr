# Hola, soy Fernando Guerrero

Fundador de **NexAI**, desde Irapuato, Guanajuato, México. Desarrollo chatbots de WhatsApp, sistemas de automatización y aplicaciones web.

## Qué construyo

- **Chatbots y mensajería en WhatsApp:** integraciones con APIs REST, flujos automatizados, colas de eventos y conectores para operación continua.
- **Automatización de procesos:** backends en Node.js y TypeScript, PostgreSQL, Redis y entrega desacoplada de webhooks.
- **Desarrollo web:** aplicaciones y paneles administrativos con React, Next.js y TypeScript.
